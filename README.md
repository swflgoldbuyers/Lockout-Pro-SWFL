# Lockout Pro SWFL

Official website for **Lockout Pro SWFL** — Southwest Florida’s mobile automotive locksmith.

- Domain: [lockoutproswfl.com](https://lockoutproswfl.com)
- Phone: **(239) 380-5240**
- Focus: Emergency automotive locksmith services only

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Regenerating inner pages

Service, location, and resource pages are generated from `build_site.py`:

```bash
python3 build_site.py
```

Hand-crafted files: `index.html`, `style.css`, `script.js`, branding assets, `CNAME`.
